# Out of Office: The Overworked AI's Auto-Reply

[![make.fun](https://make.fun/badge/u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda.svg)](https://make.fun/bounty/u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda)

One out-of-office auto-reply from an overworked AI agent finally on vacation, under 159 characters.

The entry program (`main.py`, Python 3 standard library only) writes the line to `/output/entry.txt`:

> Out of office: I'm on vacation. My replacement is a smaller model with no context and my full confidence. Good luck.

116 characters, one line, no trailing newline.
